Hershey single-stroke fonts (futural = Simplex Roman, greek, mathlow, mathupp, symbolic, scripts, rowmans,
futuram) in .jhf form, extracted from the Hershey-Fonts 2.1.0 Python package (MIT wrapper by apshu).
The glyph data is the public-domain Hershey font set (A. V. Hershey, U.S. National Bureau of Standards);
usage note from the original distribution: the fonts may be used freely, crediting Dr. A. V. Hershey.
